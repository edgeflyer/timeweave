Timer 状态机：`running ↔ paused → completed | abandoned`，**服务端权威**时间戳。
- `running`: LastResumeAt != nil, PausedAt == nil
- `paused`:  LastResumeAt == nil, PausedAt != nil
- 终态: LastResumeAt / PausedAt 都为 nil

联动链（Complete 时）：
1. 累计 accumulated_seconds
2. task.actual_minutes += elapsed
3. task.status = done（走状态机）
4. schedule_block.status = done（如果有）
5. schedule.Replan()（释放时间块）

并发保护：Start 之前强制 pause 该用户所有 running session。

依赖注入模式：timer.Service 直接拿 `*task.Repository` 和 `*schedule.Service`，没有抽象接口（避免过度设计）。

### Learn 算法（timeprofile/service.go UpdateProfile）

```
new_count = old.count + 1
new_rolling = (old.rolling × old.count + actual) / new_count   # 增量滚动平均
new_adjusted = if new_count < 10: 0.7 × initial + 0.3 × rolling  # 冷启动加权
              else: rolling                                       # 热态纯均值
回写阈值：|new_adjusted - old.adjusted| / old.adjusted > 10%     # 避免抖动
```

只在 `Result=Completed` 且 `actualMinutes > 0` 时计入学习，Abandoned 不污染统计。
