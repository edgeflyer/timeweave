## 本地启动（无 Docker）

```bash
# 1. 确保 MySQL 8.0 已本地启动
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS questos DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 改 .env 里的 DB_USER / DB_PASSWORD 匹配你的本地 MySQL
# 3. 启动服务
make run

# 4. 测试
curl http://localhost:8080/healthz
curl -X POST http://localhost:8080/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"hello123","nickname":"测试"}'
```

## 仓库配置注意点

- `.gitignore` 之前有 bug：`.*` 这一行会把 `.env.example` 也忽略；已修复为推荐版本
- `.env` 不入库，`.env.example` 必须入库（作为配置模板）
- SSH 远程代理：`~/.ssh/config` 用 `nc -X 5 -x 127.0.0.1:12450`，端口 12450 是用户的本地代理
- macOS 系统 nc 不支持 `-X 5`，SSH 走这个 ProxyCommand 必须能通过
